Browser checks at phone size (Python Playwright). Each takes the base URL as its first argument: `https://finn-network.vercel.app` for the live link, `http://localhost:4173` for `npm run preview` (the default for flows, live and walkthrough is finn-network).

- `flows.py` the brief read to the end (window, one event one figure, your lines, a card's full view and Back, the network's card, the path, Same person or Someone else), Book filter, a company and Back scroll, the annual report, Look up by company, by book (holdings first) and an unknown symbol, a filing kind switched off, Nothing needs you and its wider window, Your data, no signal; prints page errors; exits 1 on a failed check
- `live.py [base] [--presend [--no-key]]` after a finn-network deploy: a new build is live, the security headers and `X-Robots-Tag` on `/data/`, robots.txt, a grade with URLs the server never listed keeps none, the network answers equal the committed code's, MARICO with no model key says so within 2 s, finn-ledger untouched; exits 1 on a failed check. `--presend` is the gate before the email: also this commit's build and share tags, a company outside the 22 read live, the repo public on `submission`, no unfiled profile field on the link (WARN while the data still holds some). `--no-key` swaps the live read for "reading is off" and the docs' fallback sentences
- `walkthrough.py` the taps in `docs/WALKTHROUGH_SCRIPT.md`, checking every `On screen:` string; skips the optional beat when the link has no model key
- `folds.py` every fold stays visible when opened on screen
- `sweep.py` all company pages at 320 and 390 px: no sideways scroll, no NaN/undefined
- `compare.py` and `motion.py` are October's and target the finn-ledger projects (October's `ship.sh`, which pushed and deployed them, is gone). Not for this branch: it deploys only with `~/ENAM-FINN/deploy_network.sh`.
