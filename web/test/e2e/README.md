Browser checks at phone size (Python Playwright). Each takes the base URL as its first argument (default: the live link, or localhost:4173 for sweep).

- `flows.py` windows, Your lines, Book filter, company and Back scroll, Look up by name; prints page errors
- `folds.py` every fold stays visible when opened on screen
- `sweep.py` all company pages at 320 and 390 px: no sideways scroll, no NaN/undefined
- `ship.sh "message"` test, build, commit, push, deploy, and compare the live bundle with the local one
