# Roadmap

Goal: FINN good enough that ENAM would publish it as its own app, and the strongest submission for the Founding AI Engineer brief (`~/ENAM-FINN/network_brief/`). Deadline 15 Nov 2026. Process: `~/ENAM-FINN/NETWORK_SPEC4.md`. Stage: `docs/STAGE`. Plans: `docs/plans/<id>.md`.

The order is by what the submission loses if the run stops after a task. The brief grades creativity, product sense, judgment and architecture. The app has the first three on screen; the architecture is written (`docs/ARCHITECTURE.md`, six ADRs), and the writeup describes the app as the link shows it (15 Nov).

## Rules for every task
- A task that changes what the app does updates the documents that describe it (README, covering note, walkthrough, brief trace, `ARCHITECTURE.md`) before it is marked done. The repo, the live link and the writeup always agree.
- **Order from 14 Nov** (the spec's overnight guidance, which replaces the older rule that `final` comes next): `network-loop`, `trust`, `checkpoint`, `annual-report`, `ask`, `final`, polish. What each must achieve is in `docs/CONTEXT.md`.
- Thin but working. A task that can't be finished cleanly in one session is cut down in its plan, not left half built.
- **Standing live check, first thing in every execute session.** `curl -s https://finn-network.vercel.app | grep -o 'assets/index-[A-Za-z0-9_-]*\.js'`. If it is no longer `index-ndG2nx8r.js` (deployed 15 Nov at `polish`, its fourth pass), someone has deployed app changes: run `python3 web/test/e2e/live.py` and `python3 web/test/e2e/flows.py https://finn-network.vercel.app`, log the result in `docs/plans/architecture.md`, and fix what fails. If it is the old hash, carry on with the task.
- **Shippable at every task's end (from `checkpoint`).** Before a task is marked done: `python3 evals/claims.py` holds (its retired and pending phrases too), `python3 evals/ship.py --write` passes and moves `submission` to the new tree, and `docs/FINAL_CHECKLIST.md` gets the task's pass. A task that makes a pending phrase false (`annual-report`) rewrites the sentence. `final` adds `ship.py --kit` and `live.py --presend`.
- **Deploys.** Try `~/ENAM-FINN/deploy_network.sh` once per task when it has visible changes. If the permission check refuses it, don't retry: the task is done when it works in the repo and on the local preview, and the deploy goes to `docs/NEEDS_FROM_USER.md`. A blocked deploy never holds `STAGE`.

## Decided, so later sessions don't reopen it
- **The snapshot stays at 28 Oct.** The synthetic network and its 334 checks are built on that day's filings, and a demo that changes under the grader is worse than one that is dated. The app shows the date; the architecture says how it refreshes for real.
- **No background push.** It needs stored subscriptions and a scheduler. Described, not built.
- **The Network gets no screen of its own.** A person appears beside the thing they can explain (`DESIGN.md`).
- **`docs/INTERVIEW_DEFENSE.md` is the user's preparation and stays out of the public snapshot** (decided in `architecture-x`; the user may override). The grader reads ARCHITECTURE's "Where this is weak" instead.
